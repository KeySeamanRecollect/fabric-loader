# Fabric Loader

### Lightweight, fast Minecraft mod loader

Fabric Loader is a minimal, fast-updating mod loader for Minecraft. Its lightweight design allows it to update for new Minecraft versions within hours, and its API ecosystem supports thousands of community mods.

<br>

---

## Features

| | |
|:---|:---|
| **Rapid Updates** | Typically updates for new Minecraft releases within 24-48 hours |
| **Minimal Footprint** | Small core that doesn't interfere with vanilla gameplay |
| **Mixin Support** | Powerful bytecode manipulation via Mixins for complex mod interactions |
| **Rich Ecosystem** | Thousands of mods including Sodium, Iris, Lithium, and more |
